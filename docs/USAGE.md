# คู่มือการใช้งาน

## ส่วนที่ 1 — สั่งงานผ่านแชท

พิมพ์คุยกับบอทได้เลย ไม่ต้องจำรูปแบบเป๊ะ ๆ ระบบเข้าใจคำพ้องหลายแบบ

### คำสั่งหลัก

| พิมพ์ | ผลลัพธ์ |
|---|---|
| `เช็ค ปากกา` | การ์ดสินค้า + ยอดคงเหลือแยกตามคลัง |
| `เบิก ปากกา 5` | ให้เลือกคลัง → **การ์ดยืนยัน** → กดยืนยันจึงตัดสต๊อก |
| `รับเข้า กระดาษ A4 10` | เพิ่มสต๊อก |
| `ปรับ ปากกา 42` | ปรับยอดให้ตรงกับที่นับได้จริง (ใช้ตอนนับสต๊อกประจำเดือน) |
| `ย้าย ปากกา 5 @คลังกลาง @หน้าร้าน` | โอนระหว่างคลัง |
| `ใกล้หมด` | รายการที่ต่ำกว่าจุดสั่งซื้อ |
| `ประวัติ` | 10 รายการล่าสุด |
| `ประวัติ ปากกา` | ประวัติเฉพาะสินค้านั้น |
| `คลัง` | รายชื่อคลังพร้อมยอดรวม |
| `สรุป` | ภาพรวมทั้งระบบ |
| `ช่วยเหลือ` | การ์ดวิธีใช้ |
| `ยกเลิก` | ยกเลิกรายการที่ค้างอยู่ |

### ลูกเล่นที่ช่วยให้เร็วขึ้น

**ระบุคลังด้วย `@`** — ข้ามขั้นตอนเลือกคลัง
```
รับเข้า กระดาษ A4 10 @คลังกลาง
```

**ใส่หมายเหตุด้วย `#`** — บันทึกลงประวัติด้วย
```
เบิก ปากกา 5 #งานอบรมพนักงานใหม่
```

**ไม่ใส่จำนวนก็ได้** — บอทจะถามให้ แล้วพิมพ์แค่ตัวเลขตอบ
```
คุณ: เบิก ปากกา
บอท: พิมพ์จำนวนที่ต้องการ
คุณ: 5
```

**พิมพ์/สแกนบาร์โค้ดมาตรง ๆ** — เปิดการ์ดสินค้าทันที
```
8850001000018
```

**พิมพ์ชื่อสินค้าเฉย ๆ** — ระบบเข้าใจว่าเป็นการค้นหา
```
ปากกา
```

### คำพ้องที่ใช้ได้

| ความหมาย | พิมพ์ได้ว่า |
|---|---|
| เบิกออก | `เบิก` `จ่าย` `ตัดสต๊อก` `จ่ายออก` |
| รับเข้า | `รับ` `รับเข้า` `รับของ` `เติม` `เพิ่มสต๊อก` |
| ปรับยอด | `ปรับ` `ปรับยอด` `นับ` `นับสต๊อก` |
| ย้ายคลัง | `ย้าย` `โอน` |
| ค้นหา | `เช็ค` `เช็ก` `ตรวจ` `หา` `ค้นหา` `คงเหลือ` |

### เมื่อค้นเจอหลายรายการ

ระบบจะขึ้นการ์ดให้เลือกก่อนเสมอ ไม่เดาให้เอง
ถ้าอยากให้เจอตัวเดียว พิมพ์ให้เจาะจงขึ้น เช่น `เบิก ปากกา น้ำเงิน 5`

### กฎความปลอดภัยของบทสนทนา

- **ทุกรายการต้องกดยืนยันก่อนเสมอ** ไม่มีการตัดสต๊อกทันทีจากข้อความเดียว
- การ์ดยืนยันแสดง *คงเหลือปัจจุบัน* และ *คงเหลือหลังทำรายการ* ให้เห็นก่อนตัดสินใจ
- ถ้าจะทำให้ต่ำกว่าจุดสั่งซื้อ จะมีคำเตือนสีส้มขึ้นในการ์ด
- **เบิกเกินของที่มีไม่ได้** ระบบจะปฏิเสธพร้อมบอกยอดคงเหลือจริง
- ร่างรายการที่ยังไม่ยืนยันหมดอายุใน **10 นาที**

## ส่วนที่ 2 — แดชบอร์ด (LIFF)

เปิดจากปุ่ม **แดชบอร์ด** ในริชเมนู หรือลิงก์ `https://liff.line.me/<LIFF_ID>`

### แท็บ ภาพรวม
ตัวเลขสำคัญ 5 ตัว (จำนวนสินค้า · หน่วยคงเหลือรวม · ใกล้หมด · หมดสต๊อก · ความเคลื่อนไหววันนี้),
กราฟยอดตามคลัง, รายการที่ต้องเติมสต๊อก และไทม์ไลน์ความเคลื่อนไหวล่าสุด

### แท็บ สินค้า
ค้นหา กรองตามสถานะ (ทั้งหมด/ใกล้หมด/หมดสต๊อก) และกรองตามคลัง
กดที่สินค้าเพื่อเปิดรายละเอียด → ทำรายการ เบิก/รับเข้า/ปรับยอด/ย้ายคลัง ได้จากตรงนั้น
ฟอร์มจะโชว์ *คงเหลือหลังทำรายการ* แบบเรียลไทม์ก่อนกดยืนยัน

### ปุ่มสแกน (วงกลมกลางแถบล่าง)
สแกนบาร์โค้ดสินค้า → เปิดการ์ดสินค้าทันที
ถ้าสแกนแล้วไม่พบ ระบบจะถามว่าต้องการเพิ่มเป็นสินค้าใหม่พร้อมกรอกบาร์โค้ดให้อัตโนมัติ

### แท็บ ประวัติ
ดูความเคลื่อนไหวทั้งหมด กรองตามประเภทได้ แสดงผู้ทำรายการและยอดคงเหลือหลังทำทุกครั้ง

### แท็บ ตั้งค่า
เพิ่ม/แก้ไข/ลบคลัง · โพยคำสั่งแชท · ข้อมูลบัญชีผู้ใช้

## ส่วนที่ 3 — แนวทางใช้งานจริง

**ตั้งจุดสั่งซื้อขั้นต่ำ (`min_qty`) ให้ทุกสินค้า** ระบบถึงจะเตือน `ใกล้หมด` ได้ถูกต้อง
ตั้งประมาณ "ปริมาณที่ใช้ระหว่างรอของใหม่มาส่ง"

**นับสต๊อกประจำเดือน** ใช้ `ปรับ <สินค้า> <ยอดที่นับได้> #นับสต๊อกประจำเดือน`
ระบบจะบันทึกส่วนต่างไว้ในประวัติ ทำให้ตรวจสอบย้อนหลังได้ว่าหายไปเท่าไหร่

**บาร์โค้ด** ถ้าสินค้ามีบาร์โค้ดโรงงานอยู่แล้ว ใส่เลขนั้นเลย จะสแกนของจริงได้ทันที
ถ้าไม่มี พิมพ์รหัสอะไรก็ได้ที่ไม่ซ้ำ แล้วปริ้นสติกเกอร์ QR ติดเอง

**หลายคลัง** เหมาะกับกรณีมีหน้าร้าน/สต๊อกกลาง/สาขา แยกกัน
ถ้ามีที่เก็บเดียว สร้างคลังเดียวพอ ระบบจะข้ามขั้นตอนเลือกคลังให้อัตโนมัติ
