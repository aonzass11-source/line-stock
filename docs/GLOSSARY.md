# ศัพท์ที่จะเจอ แปลเป็นภาษาคน

ไม่ต้องท่องครับ เปิดดูตอนงงก็พอ ถ้าเจอคำที่ไม่มีในนี้ **ถาม AI ได้เลย** ว่า "คำนี้แปลว่าอะไร"

## ฝั่ง LINE

| คำ | แปลว่า |
|---|---|
| **Channel** | "ช่อง" ที่เราสร้างในเว็บ LINE Developers เปรียบเหมือนใบอนุญาตให้โปรแกรมเราคุยกับ LINE ได้ ระบบนี้ต้องใช้ 2 ใบ |
| **Messaging API channel** | ใบอนุญาตสำหรับ "ตัวบอท" — ตัวที่ทักแชทกับพนักงาน |
| **LINE Login channel** | ใบอนุญาตสำหรับ "หน้าเว็บแดชบอร์ด" — ใช้ยืนยันว่าคนเปิดเป็นใคร |
| **Channel secret** | รหัสลับประจำช่อง ใช้พิสูจน์ว่าข้อความที่ส่งมาเป็นของ LINE จริง ไม่ใช่คนปลอม **ห้ามให้ใคร** |
| **Channel access token** | บัตรผ่านที่โปรแกรมเราใช้สั่งให้ LINE ส่งข้อความ **ห้ามให้ใคร** ถ้าหลุดกดออกใหม่ได้ (Reissue) |
| **LIFF** | เว็บที่เปิดอยู่ในแอป LINE โดยไม่เด้งออกไปเบราว์เซอร์ = หน้าแดชบอร์ดของเรา |
| **LIFF ID** | เลขประจำหน้าเว็บนั้น หน้าตาเช่น `1234567890-abcdefgh` ไม่ใช่ความลับ |
| **Endpoint URL** | ที่อยู่เว็บของเรา ที่บอก LINE ว่า "เวลาเปิดแดชบอร์ด ให้ไปโหลดหน้าจากตรงนี้" |
| **Webhook** | ช่องทางที่ LINE ใช้ "ส่งต่อ" ข้อความของพนักงานมาให้โปรแกรมเรา ถ้าไม่เปิด บอทจะเงียบสนิท |
| **Scope** (`openid`, `profile`) | สิทธิ์ที่เราขอจากผู้ใช้ — `profile` = ขอชื่อ/รูป, `openid` = ขอบัตรยืนยันตัวตน **ต้องติ๊กทั้งคู่** |
| **Rich menu** | เมนูรูปภาพที่โผล่ด้านล่างห้องแชท กดแล้วสั่งงานได้ |
| **Auto-reply / Greeting message** | ข้อความตอบอัตโนมัติสำเร็จรูปของ LINE **ต้องปิด** ไม่งั้นจะตอบซ้อนกับบอทเรา |

## ฝั่ง Cloudflare

| คำ | แปลว่า |
|---|---|
| **Cloudflare** | บริษัทที่ให้เราฝากโปรแกรมไว้บนอินเทอร์เน็ต (แทนที่จะต้องซื้อเซิร์ฟเวอร์เอง) |
| **Worker** | ตัวโปรแกรมของเราที่ไปรันอยู่บน Cloudflare |
| **D1** | ฐานข้อมูลของ Cloudflare = สมุดบันทึกที่เก็บสินค้า คลัง และประวัติทั้งหมด |
| **Binding** | สายเชื่อมระหว่าง Worker กับ D1 ในโปรเจกต์นี้ชื่อ `DB` |
| **Deploy** | "ส่งขึ้นใช้งานจริง" — เอาโค้ดในเครื่องอัปขึ้นอินเทอร์เน็ต |
| **Migration** | คำสั่งสร้าง/แก้โครงสร้างตารางในฐานข้อมูล ต้องรันครั้งแรกครั้งเดียว ไม่งั้นฐานข้อมูลจะว่างเปล่าไม่มีตาราง |
| **Seed** | ใส่ข้อมูลตัวอย่างเริ่มต้น (3 คลัง 6 สินค้า) ไว้ลองเล่น ลบทีหลังได้ |
| **Secret** | ค่าลับที่เก็บฝั่ง Cloudflare แบบเข้ารหัส ไม่อยู่ในไฟล์โค้ด |
| **API Token** | บัตรผ่านของ Cloudflare (คนละตัวกับของ LINE) |

## ฝั่งเครื่องมือ / โค้ด

| คำ | แปลว่า |
|---|---|
| **Repository (repo)** | โฟลเดอร์โปรเจกต์ที่เก็บบน GitHub |
| **Clone** | ก๊อปโปรเจกต์จาก GitHub ลงมาไว้ในเครื่องเรา |
| **Fork** | ก๊อป repo ของคนอื่นไปเป็นของเราบน GitHub |
| **Commit / Push** | บันทึกการแก้ไข / ส่งการแก้ไขขึ้น GitHub |
| **Terminal** (เทอร์มินัล) | หน้าต่างดำ ๆ ที่พิมพ์คำสั่งได้ — ถ้าใช้ OpenCode desktop แทบไม่ต้องแตะเลย |
| **npm** | ตัวจัดการไลบรารีของ Node.js — ใช้ติดตั้งของที่โปรเจกต์ต้องใช้ |
| **wrangler** | เครื่องมือของ Cloudflare สำหรับสั่ง deploy และจัดการฐานข้อมูล |
| **`wrangler.jsonc`** | ไฟล์ตั้งค่าหลัก — เก็บ LIFF ID, Channel ID และเลขฐานข้อมูล |
| **`.dev.vars`** | ไฟล์เก็บค่าลับสำหรับทดสอบในเครื่อง **ห้ามอัปขึ้น GitHub** (มีตัวกันไว้แล้ว) |
| **Environment variable / var** | ค่าตั้งค่าที่แยกออกจากโค้ด เปลี่ยนได้โดยไม่ต้องแก้โปรแกรม |
| **Endpoint / API** | "ที่อยู่" ที่โปรแกรมเรียกหากันเพื่อขอข้อมูล |
| **Log** | บันทึกว่าโปรแกรมทำอะไรไปบ้าง ใช้หาสาเหตุเวลาพัง (`npm run tail`) |
| **Error** | ข้อความแจ้งว่ามีอะไรผิด — **เวลาเจอ ให้ก๊อปทั้งก้อนไปวางให้ AI อ่าน** |
